## 📖 Sobre o projeto

Este projeto consiste no desenvolvimento de um site moderno para fotografia, criado com foco em apresentação visual, organização do conteúdo e adaptação para diferentes tamanhos de tela.

Anteriormente, desenvolvi outro site de fotografia sem aplicar responsividade. Neste novo projeto, cada seção está sendo construída e testada desde o início para funcionar corretamente em computadores, tablets e celulares.

Dessa forma, consigo comparar os dois trabalhos e acompanhar claramente minha evolução no desenvolvimento front-end.

## 🎯 Objetivos

- Criar uma experiência visual moderna e profissional.
- Aplicar responsividade durante todo o desenvolvimento.
- Melhorar a organização e a manutenção do código.
- Aprimorar minhas habilidades com HTML, CSS e JavaScript.
- Oferecer uma boa experiência em diferentes dispositivos.

## ✨ Funcionalidades

- Apresentação dos serviços fotográficos.
- Portfólio para exibição dos trabalhos.
- Navegação com GSAP e intuitiva.
- Seções organizadas e adaptáveis.
- Área de contato.
- Layout responsivo para desktop, tablet e celular.

## 📱 Responsividade

O layout está sendo desenvolvido utilizando:

- Unidades de medida flexíveis.
- Flexbox.
- CSS Grid.
- Imagens responsivas.
- Media queries.
- Breakpoints para diferentes dispositivos.
- Testes frequentes durante o desenvolvimento.

## 🚀 Tecnologias utilizadas

- **HTML5** — estrutura e semântica.
- **CSS3** — estilização e responsividade.
- **JavaScript** — interações e funcionalidades.
